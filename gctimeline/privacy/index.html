Privacy Policy

GC Timelineにおけるユーザーデータの取り扱いについて

1. はじめに

GC Timeline（以下「本アプリ」）は、Google Calendarに登録された予定を iOSのホーム画面上で確認するための個人開発アプリケーションです。 本プライバシーポリシーでは、本アプリが取得する情報とその利用目的について説明します。

2. 取得する情報

本アプリは、Google Calendar APIを利用して、 Google Calendarに登録されている予定情報を取得します。

  • 予定の日時
  • 予定のタイトル（取得が許可されている場合）
  • 予定の公開状態や予定種別など、表示に必要な情報
  • カレンダーを識別するために必要な情報

3. 情報の利用目的

Google Calendarから取得した情報は、 本アプリのウィジェット上にカレンダー予定を表示する目的でのみ使用します。

取得した情報を、広告、マーケティング、ユーザー分析その他の目的に 使用することはありません。

4. Googleアカウントへのアクセス

本アプリはGoogle OAuth 2.0およびGoogle Calendar APIを利用して、 Google Calendarの情報へアクセスします。 アクセスは、本アプリの機能を提供するために必要な範囲に限定されます。

5. 情報の保存

Google Calendarから取得した予定情報は、 ウィジェット上に予定を表示するために必要な範囲で端末上で処理されます。 本アプリの開発者が管理する外部サーバーへ、 Google Calendarの予定情報を送信または保存することはありません。

6. 第三者への提供

本アプリは、Google Calendarから取得したユーザーデータを 第三者へ販売、提供または共有しません。

7. データへのアクセスの停止

本アプリによるGoogleアカウントへのアクセスは、 Googleアカウントの設定からいつでも取り消すことができます。 アクセスを取り消した後、本アプリはGoogle Calendarの情報を 新たに取得できなくなります。

8. Google API Services User Data Policy

本アプリによるGoogle APIから取得した情報の利用は、 Google API Services User Data Policyに従います。

9. プライバシーポリシーの変更

本アプリの機能変更や利用するAPIの変更などに伴い、 本プライバシーポリシーを変更する場合があります。 変更後の内容は本ページに掲載します。

10. お問い合わせ

本アプリおよび本プライバシーポリシーに関するお問い合わせは、 GitHubアカウント moka129 までお願いします。
